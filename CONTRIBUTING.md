# Contributing to MiBee Eye

Thanks for your interest in contributing! 

📖 **Full contributing guide**: see [docs/en/contributing.md](docs/en/contributing.md) (English) or [docs/zh/contributing.md](docs/zh/contributing.md) (中文).

## Quick Start

```bash
git clone https://github.com/xiqing85/mibee-eye-notebook.git
cd mibee-eye
cargo build
cargo test
```

## Reporting Issues

Please use [GitHub Issues](https://github.com/xiqing85/mibee-eye-notebook/issues) to report bugs or request features.
